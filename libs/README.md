# GeckoLib 编译依赖

`geckolib-neoforge-26.2-5.5.6.jar` 是本移植工作区原有的 GeckoLib 5.5.6 / NeoForge 26.2 编译依赖，由 `build.gradle.kts` 通过本地文件引用。

- 项目：<https://github.com/bernie-g/geckolib>
- 作者和贡献者：以 JAR 内的 `META-INF/neoforge.mods.toml` 为准。
- 许可：MIT，原始许可保留于 JAR 内的 `LICENSE.txt`。
- SHA-256：`32f91b9e6d5f62dab0740a0cec1a1f5619aaa07a0249c250df2f7918eb0c30e2`

此依赖用于编译和开发运行；它不会打入 DragonMineZ 的发行 JAR。玩家仍需在游戏的 `mods` 目录安装对应版本的 GeckoLib。
